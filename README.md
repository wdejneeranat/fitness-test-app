# fitness-test-app

The assessment form records measured values for Forward Reach, Dead Hang, 30-Second Sit-to-Stand, and Vertical Jump, then applies the age- and gender-specific cut-offs and interpretation guidance in the supplied workbook. The attached station illustrations are stored in `assets/`.

The results action opens the browser print dialog and prepares an email in the user's default email application. The user must confirm printing and send the email; this standalone frontend does not send email in the background.
